# Ohio Drivers Knowledge Practice Quiz

A phone-friendly practice quiz covering Ohio BMV knowledge-test topics from the Ohio Driver Manual.

This is **not** the official Ohio BMV knowledge test. It is an unofficial study tool so you can practice on a phone or computer.

## Open on a phone

- GitHub file: https://github.com/TimbrCAD/ohio-drivers-quiz/blob/main/index.html
- jsDelivr (best for phones): https://cdn.jsdelivr.net/gh/TimbrCAD/ohio-drivers-quiz@main/index.html

On iPhone, open the jsDelivr link, then tap Share → Add to Home Screen if you want an icon.
